# WinStars3-FDroid

WinStars 3 is no longer available on the Google Play Store. You can now install it and receive future updates in two ways:

- Via F-Droid (Recommended): Add the official repository to your F-Droid application... [https://franckrichard01.github.io/WinStars3-FDroid/repo/](https://franckrichard01.github.io/WinStars3-FDroid/repo/)


- By direct download: Download the APK corresponding to your architecture (arm64-v8a | armeabi-v7a | x86_64 | x86).
Requires enabling unknown sources.
